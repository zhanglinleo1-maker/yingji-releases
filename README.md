# 映记 · 下载与更新

映记用于本地视频与照片回顾、口述记录和素材资料整理。

本仓库只作为版本说明与经确认安装包的发布渠道，不包含应用源码、剪辑Skill或详细执行规则；发布渠道公开不代表这些内容已开源。

**当前尚未在本仓库发布可下载的应用版本。** `version.json`的空列表是有意保留的状态，不代表某个内测包已正式发布，也不代表当前用户已经是最新版。

后续只有完成确认的版本才会出现在发布列表中。GitHub发布后由维护者手动同步至Gitee；Gitee国内渠道需完成公开访问与文件下载验证后启用。请勿把其他项目或不明来源的文件当作映记更新。

更新检查仅获取公开版本信息，不自动下载、安装或强制升级。测试版和正式版分开比较。

维护者发布格式与步骤见[发布维护说明](发布维护说明.md)。
